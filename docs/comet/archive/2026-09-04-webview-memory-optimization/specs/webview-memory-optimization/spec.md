# WebView2 与进程内存优化规格

## 概述

定义 ClipOne 针对 WebView2 与主程序的内存优化规范，涵盖后台空闲工作集修剪（Working Set Trim）、Chromium 启动参数调优、基于 ID 的轻量前后端 IPC 交互以及前端 DOM 分批按需渲染，确保在零卡顿、无感秒级唤起的前提下大幅降低物理内存占用。

## 场景规范

### Scenario: 后台静默时自动修剪进程工作集内存
GIVEN ClipOne 与 WebView2 正在运行且窗口处于隐藏状态
WHEN 窗口隐藏超过空闲延迟阈值（如 3 秒）
THEN ClipOne 主进程及关联的 msedgewebview2.exe 进程物理工作集内存（Working Set）被自动修剪，总物理内存占用大幅下降至 30MB 以下，且按快捷键唤出窗口时仍能毫秒级即时展示且无白屏或闪烁

### Scenario: 前端列表按需分批渲染
GIVEN 剪贴板历史中存在多条记录（最多 300 条）
WHEN 用户打开剪贴板窗口或搜索过滤
THEN 前端优先渲染可见视口及首屏条目（如 25 条），随滚动接近底部时自动追加渲染后续条目，避免一次性生成上千个 DOM 节点与显存纹理

### Scenario: 粘贴与设置剪贴板基于 ID 交互
GIVEN 用户在前端选中某条历史记录并触发粘贴或复制
WHEN 前端向 C# 宿主发送 IPC 消息
THEN 前端仅发送条目 Id，C# 宿主根据 Id 从本地存储中检索完整数据并写入系统剪贴板，彻底杜绝大文本在 IPC 与 V8 堆中的全量序列化往返
